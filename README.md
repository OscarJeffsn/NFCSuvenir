# NMRT Souvenir NFC Demo

Готовый статический лендинг для публикации через GitHub Pages.

## Что уже подготовлено

- главный файл сайта: `index.html`
- служебный файл для GitHub Pages: `.nojekyll`

## Как задеплоить

1. Создай новый репозиторий на GitHub.
2. Загрузи в него содержимое этой папки.
3. Открой `Settings` -> `Pages`.
4. В блоке `Build and deployment` выбери `Deploy from a branch`.
5. Укажи ветку `main` и папку `/ (root)`.
6. Сохрани настройки и подожди 1-3 минуты.

После этого сайт будет доступен по адресу вида:

`https://username.github.io/repository-name/`

## Что можно доделать позже

- подключить реальные фотографии вместо заглушек в карусели
- подключить настоящее аудио для кнопки "Слушать историю"
- добавить собственный домен или короткую ссылку для NFC-метки
